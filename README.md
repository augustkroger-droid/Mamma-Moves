# Mamma Moves

Mamma Moves is a mobile-first PWA for short personal workout sessions built with Next.js, TypeScript and Supabase.

## Local setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create `.env.local`:

   ```bash
   NEXT_PUBLIC_SUPABASE_URL=
   NEXT_PUBLIC_SUPABASE_ANON_KEY=
   ```

3. Run the app:

   ```bash
   npm run dev
   ```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
